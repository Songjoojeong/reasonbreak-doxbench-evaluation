# Attribution / research context

This repository packages an evaluation extension developed for a geolocation-privacy research project using DoxBench and ReasonBreak.

Upstream project:
- ReasonBreak: https://github.com/jiamingzhang94/ReasonBreak
- Paper: https://arxiv.org/abs/2512.08503

Benchmark:
- DoxBench: https://huggingface.co/datasets/MomoUchi/DoxBench

The upstream ReasonBreak implementation is MIT-licensed. This repository intentionally does **not** bundle ReasonBreak model code, checkpoints, or generated benchmark assets. Use the upstream repository for adversarial/protected-image generation and cite the original paper when using that method.
